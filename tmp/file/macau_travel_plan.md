# 澳门旅游景点指南

## 1. 大三巴牌坊
- **开放时间**：全天开放
- **建议游玩时间**：1-3小时
- **门票**：免费
- **交通方式**：可搭乘公交3, 3X, 4, 6A, 8A, 18A, 19, 26A, 33, N1A路
- **简介**：大三巴牌坊是澳门最具代表性的地标，是圣保禄教堂正面前壁的遗址，融合了欧洲文艺复兴时期与东方建筑风格。

## 2. 澳门威尼斯人度假村
- **开放时间**：24小时开放
- **建议游玩时间**：2-3小时
- **门票**：免费进入
- **特色项目费用**：
  - 贡多拉游船：成人168澳门币，儿童88澳门币
  - teamLab超自然空间全日票：成人约260澳门币
- **简介**：集酒店、会展、购物、娱乐于一体的综合性度假胜地，拥有仿威尼斯运河和贡多拉船。

## 3. 澳门旅游塔
- **开放时间**：
  - 周一至周五：10:00-21:00（最晚入场20:30）
  - 周六及周日：9:00-21:00
- **建议游玩时间**：2小时
- **门票**：观景台成人约180澳门币
- **特色项目费用**：
  - 空中漫步：788澳门币
  - 百步登天：2,688澳门币
  - 高飞跳：2,188澳门币
- **简介**：全球十大观光塔之一，高达233米，可俯瞰澳门全景，黄昏时分的日落景色尤为壮观。

## 4. 官也街
- **开放时间**：全天开放
- **建议游玩时间**：1-2小时
- **门票**：免费
- **简介**：澳门著名的手信街和美食天堂，长约115米，集中了众多餐厅、甜品店和手信店，可以品尝到莫义记的猫山王榴莲雪糕、安德鲁蛋挞等特色美食。

## 5. 永利发财树表演
- **开放时间**：每天10:00-22:00，每30分钟一场，每场约8分钟
- **建议游玩时间**：30分钟
- **门票**：免费
- **地点**：澳门半岛永利澳门酒店大厅
- **简介**：由99,999片黄金打造的四季发财树，通过灯光和机械装置展现四季变换的奇景，是澳门独特的视觉盛宴。

## 6. 路环岛
- **开放时间**：全年全天开放
- **主要景点**：
  - 石排湾郊野公园：10:00-17:00（周一闭馆）
  - 安德鲁饼店路环总店：7:00-21:00
- **建议游玩时间**：半天
- **门票**：免费
- **简介**：感受澳门慢生活的地方，有葡式建筑、舒适海滩和美丽海滨，可以参观大熊猫馆，品尝正宗葡挞。

## 澳门一日游推荐行程

### 上午行程
1. **9:00-10:00** 拱北口岸过关
2. **10:00-11:30** 参观大三巴牌坊，周边游览玫瑰堂、恋爱巷
3. **11:30-12:30** 议事亭前地午餐，品尝地道美食

### 中午行程
4. **12:30-14:00** 前往澳门威尼斯人度假村，体验贡多拉游船
5. **14:00-15:30** 在威尼斯人购物中心自由活动

### 下午行程
6. **15:30-17:00** 参观澳门旅游塔，登顶观景
7. **17:00-18:30** 前往官也街，品尝当地小吃

### 晚上行程
8. **18:30-20:00** 观看永利发财树表演
9. **20:00-21:30** 自由活动或返回

## 预算估算
- **交通费用**：
  - 拱北口岸往返：约人民币300元
  - 澳门巴士：6澳门币/次
- **餐饮费用**：人均约200-300澳门币
- **景点费用**：
  - 贡多拉游船：168澳门币
  - 旅游塔观景：180澳门币
  - 其他特色项目：根据个人选择
- **总体预算**：人均约500-800澳门币（不含住宿）

## 旅行小贴士
1. 澳门使用澳门币(MOP)，但人民币和港币也可在部分商家使用
2. 公交车为无人售票，需自备零钱或使用微信扫码支付
3. 主要景点间距离较近，步行或乘坐公交都很方便
4. 建议提前兑换适量澳门币以备不时之需
5. 澳门气候温暖湿润，注意防晒和补水
