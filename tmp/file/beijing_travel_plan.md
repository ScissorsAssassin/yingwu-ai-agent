# 北京旅游景点指南

## 最佳旅游时间

北京四季分明，每个季节都有其独特魅力：

- **春季（3-5月）**：气温适中（15-25℃），适合户外活动。3月下旬至4月初可赏玉渊潭樱花，4月故宫海棠与红墙相映，是摄影爱好者的理想时节。
- **秋季（9-11月）**：天高气爽，香山红叶（10月中旬最佳）、八达岭长城秋色迷人，是北京旅游的黄金季节。
- **夏季（6-8月）**：炎热多雨，但文化活动丰富，如音乐节、夜市，需注意防暑防晒。
- **冬季（12月至次年2月）**：寒冷干燥，银装素裹的故宫别有一番风味，适合体验北京传统文化。

> 推荐旅行季节：**春秋两季**

## 交通方式

### 市内交通

- **地铁**：覆盖主要景点，运营时间一般为5:00-23:00。推荐使用支付宝“出行”功能或下载“亿通行”APP扫码乘车。
- **公交**：票价便宜，适合短途出行。可使用北京公交APP或刷交通卡。
- **出租车/网约车**：起步价约14元，适合多人出行或携带行李时使用。

## 主要景点及门票价格

### 1. 故宫博物院
- **门票**：旺季60元/人（4月1日-10月31日），淡季40元/人（11月1日-次年3月31日）
- **开放时间**：08:30-17:00（周一闭馆）
- **建议游玩时间**：4-6小时
- **游览路线**：午门进 → 太和殿 → 中和殿 → 保和殿 → 慈宁宫 → 寿康宫 → 西六宫 → 御花园 → 神武门出
- **Tips**：需提前7天在“故宫博物院”微信公众号预约，节假日票务紧张

### 2. 颐和园
- **门票**：旺季30元/人，淡季20元/人
- **游船费用**：约60元/人（可选）
- **开放时间**：07:00-18:00
- **建议游玩时间**：3-4小时
- **游览路线**：新建宫门进 → 十七孔桥 → 南湖岛 → 仁寿殿 → 昆明湖 → 长廊 → 佛香阁 → 北宫门出

### 3. 天坛公园
- **门票**：旺季15元/人，联票35元/人；淡季10元/人，联票30元/人
- **开放时间**：07:00-17:30
- **建议游玩时间**：2-3小时
- **核心景点**：祈年殿、回音壁、圜丘

### 4. 八达岭长城
- **门票**：45元/人
- **交通费**：877路公交12元/单程，S2线火车约8元/单程
- **缆车/滑车**：来回80-100元
- **开放时间**：06:30-19:00
- **建议游玩时间**：3-4小时
- **Tips**：建议早出发避开人流高峰，穿舒适运动鞋

### 5. 天安门广场
- **门票**：免费
- **升旗仪式**：需提前在“天安门广场”微信小程序预约
- **建议观看时间**：根据当日日出时间确定
- **周边景点**：人民英雄纪念碑、国家博物馆（需预约）、毛主席纪念堂（需预约）

## 推荐5日游行程计划

### Day 1：抵达北京 + 天安门区域
- 上午：抵达北京，入住酒店
- 下午：天安门广场参观（人民英雄纪念碑、国家博物馆）
- 傍晚：前门大街步行街，品尝北京小吃
- 晚上：王府井夜市体验

### Day 2：故宫深度游
- 上午：故宫博物院参观（建议8:30开门即入）
- 下午：景山公园（俯瞰故宫全景）+ 北海公园
- 晚上：什刹海酒吧街或胡同游

### Day 3：八达岭长城一日游
- 上午：乘坐S2线或877路公交前往八达岭长城
- 中午：长城脚下用餐
- 下午：登长城，可选择缆车上下
- 晚上：返回市区，休息调整

### Day 4：颐和园 + 圆明园
- 上午：颐和园游览（重点长廊、佛香阁、昆明湖）
- 下午：圆明园遗址公园参观
- 晚上：中关村或五道口美食体验

### Day 5：天坛 + 返程
- 上午：天坛公园参观（感受古代祭天文化）
- 中午：南锣鼓巷逛特色小店，品尝老北京炸酱面
- 下午：根据航班/火车时间返程

## 旅行小贴士

1. **提前预约**：故宫、国家博物馆、毛主席纪念堂等热门景点需提前在线预约
2. **证件携带**：身份证必带，多数景点入园需刷身份证
3. **穿着建议**：舒适的运动鞋必备，北京景点面积大，步行量大
4. **天气准备**：春秋季早晚温差大，建议携带外套；夏季注意防晒；冬季注意保暖
5. **饮食提示**：豆汁、焦圈等特色食品可能不合所有人胃口，可先少量尝试
6. **安全提示**：保管好个人财物，尤其在人流密集区域
