# 恋爱关系维护全攻略

## 一、沟通类问题
### 1. 总是因小事争吵怎么办？
**需求**：建立有效冲突解决机制  
**解决方案**：
- 实施「24小时冷静期」规则
- 使用「非暴力沟通」模板：  
  `"当<事件>发生时，我感到<情绪>，因为我需要<需求>，能否<具体请求>？"`

### 2. 对方不愿意分享内心想法
**需求**：创造安全表达环境  
**行动方案**：
- 每周进行「3×3分享」


## 二、信任与边界
### 3. 该如何处理异性朋友关系？
**需求**：明确社交界限  
**操作指南**：
- 共同制定「社交公约」：  
  | 情景            | 你的底线     | 对方底线     |  
  |----------------|-------------|-------------|  
  | 单独聚餐        | 提前报备     | 不超出4小时 |  
  | 社交媒体互动    | 不评论亲密话题| 不加新异性好友|

## 三、关系升级
### 4. 何时适合同居？
**评估工具**：同居准备度检查表
- [ ] 已处理过3次重大冲突
- [ ] 互相知道对方的财务情况
- [ ] 讨论过家务分工方案
