# 单身期恋爱指南：自我提升与机会把握

## 常见问题
### Q1：如何克服社交恐惧认识新朋友？
**需求**：拓展社交圈但缺乏方法  
**答案**：
- 参加兴趣小组（如读书会/运动俱乐部）
- 尝试低压力社交APP（如豆瓣同城）
- 练习「3分钟搭话法」：观察对方衣物/行为找话题

### Q2：总遇到"不合适"的人怎么办？
**需求**：明确择偶标准  
**解决方案**：
1. 制作「择偶清单」：分核心需求（如责任感）和理想项（如兴趣爱好）
2. 参加「价值观优先」的社交活动（如志愿者项目）
